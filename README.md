# 🌍 Сайт вигаданої країни

## 📌 Про проєкт
Цей сайт створений для демонстрації вигаданої країни, яка існує лише у межах авторської фантазії. Уся інформація, включаючи історію, географію, політику та інші деталі, є повністю вигаданою.

## ✍️ Авторство
Автор цього проєкту самостійно придумав цю країну, її світ та всі пов’язані елементи. Будь-які збіги з реальними державами, подіями або людьми є випадковими.

## ⚠️ Важливо
- Це **не реальна країна**
- Уся інформація є художнім вигадуванням
- Проєкт створений лише для розваги та творчості

## 🎯 Мета сайту
- Розвиток креативності
- Створення унікального вигаданого світу
- Демонстрація веб-розробки

## 🛠️ Технології
- HTML
- CSS
- (за потреби можна додати JavaScript)

## 📖 Примітка
Проєкт може оновлюватися та розширюватися новими вигаданими елементами світу.
